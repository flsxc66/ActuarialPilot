# 公开产品条款（PDF）

本目录用于存放公开的保险产品条款 PDF，供 RAG 系统检索问答使用。

## 推荐数据集（公开且合规）

1. **银保监会公开审批的保险产品条款**
   来源：<https://www.cbirc.gov.cn>

2. **各大保险公司官网"公开披露"的代表性产品条款**
   如：平安、国寿、太保、太平、新华等公司的定期寿险/终身寿险/年金险条款。

3. **保险行业协会发布的示范条款**
   来源：<https://www.iac.org.cn>

## 添加新的 PDF

直接将 PDF 放入本目录即可。首次启动 Streamlit UI 时会提示是否建立索引。

## 数据合规

- 仅收录**已公开披露**的保险条款
- 不收录未公开的内部精算报告或客户隐私数据
- 在 RAG 回答时会附原文出处页码，确保可审计
