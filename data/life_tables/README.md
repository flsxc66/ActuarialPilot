# 生命表数据来源

## ⚠️ 重要声明

本目录下的生命表 CSV 是 **参考合成数据**，用于演示精算公式计算流程，
**不应用于实际保险产品定价**。

实际产品定价请使用：
- 中国银保监会发布的官方生命表
- 中国精算师协会认证的生命表
- SOA / IAE 经验生命表（北美参考）

## 文件说明

| 文件 | 说明 |
|---|---|
| `CLA2020_male.csv`   | 男性生命表（0–120 岁，qx 已线性插值填充） |
| `CLA2020_female.csv` | 女性生命表（0–120 岁，qx 已线性插值填充） |

## CSV 格式

```csv
age,sex,qx
0,M,0.000829
1,M,0.000634
...
```

- `age`: 整数年龄，0 表示刚出生
- `sex`: `M` (男性) / `F` (女性)
- `qx`: x 岁的死亡率（死亡概率，已是合法的小数）

## 重新生成

```bash
python scripts/generate_life_table.py
```

## 数据参考依据

合成数据的关键节点参考了：
- CLA2020 公开摘要（2020 年发布的中国人身保险业经验生命表）
- SOA 2017 IAM Period Table
- Bowers 等《Life Contingencies》教材中的示例生命表
